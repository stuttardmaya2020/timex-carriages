# Timex Carriages

Redesign of the website for Timex Carriages, an executive chauffeur service in London.

Static HTML, CSS and JavaScript with no build step, hosted on GitHub Pages.

- `index.html` – page content
- `styles.css` – design tokens and layout
- `script.js` – photo fallbacks and scroll fade-ins

Run it locally by opening `index.html` in a browser, or `python3 -m http.server` in this folder.
